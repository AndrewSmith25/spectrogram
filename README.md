# Spectrogram Viewer

Generates a spectrogram using the short-time Fourier Transform with customizable parameters for time resolution and window overlap.

Supported file formats are: `wav`, `avi`, `mp3`, `ogg`.

## Application Controls

Playback:

- `SPACE`: play/pause
- `Left`: step one second back
- `Right`: step one second forward
- `Shift+Left`: step five seconds back
- `Shift+Right`: step five seconds forward

Parameters

- `Up`: increment time resolution
- `Down`: decrement time resolution
- `Ctrl+Up`: increment window overlap
- `Ctrl+Down`: decrement window overlap
- `Shift`: 5x increment/decrement
